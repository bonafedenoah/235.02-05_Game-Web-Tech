Big Ideas

  • Accessibility: screen readers read your HTML aloud

HTML Essentials

Element Anatomy

  • <p> opening tag + content + </p> closing tag = the element
  • Attributes: name="value", separated by spaces
  • Void elements have no closing tag: <br>, <img>, <hr>, <meta>, <link>
  • Elements nest, never overlap. Extra whitespace collapses. Comments: <!-- -->
  • Block (p, h1, div) takes a new line; inline (a, img, em, span) flows in it

Valid vs Invalid HTML

  • ✅ <a href="http://google.com">google</a>

  • ✅ <em>hey</em>

  • ✅ <p>First line<br>Second line</p>

  • ❌ <href="filename.html">Link</href> (no tag name)

  • ❌ <img "screenshot.jpg"> (missing src=)

  • ❌ <strong>boom<\strong> (wrong slash)

  • ❌ <p><ul><li>Maze</li></ul></p> (no list inside a paragraph)

Link Pseudo-Classes

Order matters! LVFHA ("Lord Vader's Former Handle, Anakin")

a:link { color: green; }        /* unvisited */
a:visited { color: gray; }      /* visited */
a:focus { background: lightgray; }  /* keyboard focus */
a:hover { background: lightgray; }  /* mouse over */
a:active { color: blue; }       /* being clicked */

Layout Techniques

Floats & Positioning

  • float: left | right: text wraps around it. clear: both = no floats beside me
  • shape-outside: circle(50%) wraps text around a shape or an image's transparent pixels
position In the flow? top/left offsets from
static yes (default) —
relative yes where it would have been
absolute no nearest positioned ancestor (else the page)
fixed no the viewport (stays put when you scroll)
sticky yes sticks at that offset as you scroll past

z-index: higher number on top; otherwise later HTML is on top.

Flexbox

Enable: display: flex;

Key Facts:

  • Direct children become flex items (not grandchildren)
  • Default: items line up in a row (main axis)
  • flex-direction: row-reverse → right to left
  • flex-wrap: wrap → allow multiple lines
  • justify-content splits leftover main-axis space (center, space-between, space-around)
  • align-items places items in each row; align-content spaces the rows
  • flex: 1 0 200px = grow, shrink, basis: grows, won't shrink, starts at 200px

Example:

#container {
  display: flex;
  flex-direction: row-reverse;
  flex-wrap: wrap;
}

CSS Grid

Enable: display: grid;

Key Properties:

  • grid-template-columns / grid-template-rows - Define tracks
  • grid-template-areas - Named areas (ASCII art style)
  • gap - Spacing between tracks
  • Lines count from 1; -1 is the last: grid-column: 1 / -1;

Example with Named Areas:

#container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "left main right"
    "footer footer footer";
}

#header { grid-area: header; }
#left_sidebar { grid-area: left; }
#main { grid-area: main; }
#right_sidebar { grid-area: right; }
#footer { grid-area: footer; }

Responsive Web Design

RWD Core Concepts

  • ONE page at same URL serves all devices
  • Different CSS rules based on screen size
  • Mobile-first approach: use min-width media queries
  • Breakpoint: where the CSS switches; put it where your design breaks

True:

  • RWD serves one page, at one URL, with styling that adapts to the device

False:

  • RWD means the server sends phones a different site (that's the older m-dot approach, like m.facebook.com)

Media Queries (Mobile-First)

/* Mobile base styles */
body { font-size: 14px; }

/* Tablet+ */
@media (min-width: 768px) {
  body { font-size: 16px; }
}

/* Desktop+ */
@media (min-width: 1024px) {
  body { font-size: 18px; }
}

min-width = this wide or wider; max-width = this wide or narrower. Queries go after base styles.

Key Processes

Site Design Process (in order)

  1. Define the Purpose
  2. Consider the Audience
  3. Gather Ideas
  4. Organize Information
  5. Determine Navigation
  6. Sketch the Pages
  7. Build Pages
  8. Test
  9. Iterate

(After launch: Maintain, Archive.)

HTTP Request Process (in order)

  1. Type URL or click link
  2. Browser asks DNS for the IP address
  3. Browser sends HTTP request
  4. Server looks for file, sends response header
  5. Server sends file (if found)
  6. Browser parses document
  7. Browser requests images/CSS/scripts
  8. Browser assembles complete page
